# Modul 5 - CRUD Sederhana dengan PHP

## Tujuan
- Memahami dasar penggunaan form HTML.
- Mengirim data ke server menggunakan PHP.
- Memproses data dengan metode POST.

## Prasyarat
Pastikan PHP sudah terinstal dan server lokal seperti XAMPP atau MAMP sedang berjalan.

## Struktur File
- `index.php`: Menampilkan data dalam bentuk tabel.
- `tambah.php`: Form untuk menambahkan data.
- `edit.php`: Form untuk mengedit data.
- `hapus.php`: Untuk menghapus data berdasarkan ID.
- `koneksi.php`: Berisi konfigurasi koneksi ke database.

## Cara Menjalankan
1. Jalankan server lokal.
2. Akses `index.php` melalui browser.
3. Tambah, edit, atau hapus data dari tabel.

## Hasil
CRUD berjalan sesuai fungsinya: data bisa ditambah, diperbarui, dan dihapus dari database melalui tampilan web.
