# Modul 6 - CRUD Bersih dengan PHP (Refactor)

## Deskripsi
Modul ini merupakan versi bersih dan lebih terstruktur dari modul sebelumnya, tanpa file tambahan selain file inti untuk operasional CRUD. Modul ini cocok sebagai implementasi akhir dari manajemen data produk menggunakan PHP.

## Daftar File
- `index.php` – Menampilkan data dari database.
- `tambah.php` – Form untuk menambahkan data.
- `edit.php` – Mengedit data produk.
- `hapus.php` – Menghapus data berdasarkan ID.
- `koneksi.php` – Koneksi ke database.

## Tujuan
- Merapikan struktur kode PHP.
- Mengoptimalkan sistem CRUD sederhana.
- Melatih keterampilan mengelola banyak file dalam satu modul.

## Prasyarat
Gunakan server lokal (XAMPP/MAMP) dengan konfigurasi database yang sama seperti modul 5.
