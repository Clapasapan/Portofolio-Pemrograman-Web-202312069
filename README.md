# Modul 4 - Formulir dan Metode POST

## Tujuan
- Memahami dasar penggunaan form HTML.
- Mengirim data ke server menggunakan PHP.
- Memproses data dengan metode POST.

## Prasyarat
Pastikan PHP sudah terinstal dan server lokal seperti XAMPP atau MAMP sedang berjalan.

## Daftar File
- `index.php` - Halaman utama yang menampilkan data dari database.
- `tambah.php` - Formulir untuk menambah data.
- `edit.php` - Halaman untuk mengedit data yang sudah ada.
- `hapus.php` - Skrip untuk menghapus data.
- `koneksi.php` - Skrip koneksi ke database.

## Deskripsi
Modul ini berfokus pada bagaimana mengelola data dari form HTML menggunakan metode POST. Data yang dikirim dari form akan diproses oleh PHP dan disimpan ke dalam database. Selain itu, disediakan fitur edit dan hapus untuk manajemen data yang lebih lengkap.
